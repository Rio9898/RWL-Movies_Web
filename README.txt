RWL Movies Web v9 Premium
=========================
Upload the CONTENTS of this folder to the root of RWL-Movies_Web.
Do not mix files from v8 and v9.

Highlights
- Original premium cinematic redesign inspired by modern streaming UX patterns.
- 10-title Spotlight carousel (no trailer autoplay on Home).
- Dedicated detail pages, cast profiles, seasons/episodes, recommendations.
- RWL DIRECT + RWL TOT server lanes with generic Server labels.
- Premium full-screen player: ±10s, hold for 2x, quality, audio, subtitles, AirPlay, PiP, native iPhone fullscreen.
- Subtitle center grouped by language with Arabic and English priority.
- Manga search/details/chapters/reader through RWL Gateway.
- Modern settings with 7 full visual themes, playback preferences, subtitles, cloud services, sync, backup/restore.

Requires the RWL Gateway version shipped with iOS 1.2.34 or later.
No API secret is embedded in the website bundle.
