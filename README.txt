RWL Movies Web Prototype
========================

نسخة واجهة ويب تجريبية مبنية بصرياً على RWL Movies iOS v1.2.25.

التشغيل:
1) افتح index.html مباشرة في Safari / Chrome.
2) أو شغّل مجلد الموقع بأي static web server.

الموجود في النموذج:
- واجهة رئيسية RWL Movies.
- Hero / Trailer placeholder.
- قوائم Top 10 و Continue Watching.
- صفحة تفاصيل.
- RWL DIRECT مع أسماء Cinejoy / VidAPI / VidSrc.
- مشغل ويب تجريبي.
- زر Full Screen يعمل عبر Browser Fullscreen API.
- تبديل عربي / English.

ملاحظة:
هذا Prototype للواجهة والتجربة فقط. لا يحتوي على روابط بث حقيقية أو مفاتيح API أو Gateway secrets.
